# 05_bitcoin_independent — Bitcoin / Independent — general Bitcoin research

The broad **general Bitcoin topic** from V15. Use it for Bitcoin itself, regardless of any Blockstream product or brand.

## Put here

- BIPs, protocol specs, consensus/security, Taproot/Tapscript, cryptographic signatures, UTXOs, descriptors, BIP32/BIP39, wallet recovery and privacy.
- Mining/difficulty, monetary properties, Bitcoin Core releases, decentralization, Tor/I2P, node-operator security and reproducible builds.
- Cypherpunk history, independent implementations, community projects, technical papers, diagrams and demonstrations not centered on Blockstream.

## Keep elsewhere / avoid

- Specific read-only Bitcoin Core JSON-RPC experiment/tutorial → `../06_bitcoin_full_node_rpc/`.
- Core Lightning implementation/plugins → `../10_blockstream_core_lightning/`; general Lightning protocol concepts can stay here.
- A Blockstream product/brand-specific announcement → that product’s folder.

## Filing routine (keep the folder flat)

1. Save papers, images, code, links, screenshots, notes and finished posters **directly in this folder**. No required child folders.
2. Give every sourced item a readable filename; include the project/version/date when that affects accuracy. Preserve the official original filename of authentic product photos when possible.
3. For anything used in a public tweet/poster, keep the **primary source URL, checked date, relevant release/network version, and usage/redistribution rights** in a nearby `.md` note or directly below in this README.
4. Treat source documents as evidence, not permission to alter branded artwork. Before publishing, recheck time-sensitive claims and avoid exposing wallet secrets, authentication material or private user data.
