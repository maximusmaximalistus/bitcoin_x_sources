# 00_shared_assets — Shared authentic assets and reusable media

The canonical home for **reusable source assets** used by more than one editorial topic. This is a library, not a new subtopic category.

## Put here

- Original unmodified official logos, icon packs, wordmarks and brand-guideline references (with licensing information).
- Authoritative Blockstream hardware photographs and rotation videos, particularly the authentic Jade Plus Grey images.
- Reusable typography assets where redistributing or storing them is permitted, generic textures, diagrams, and shared illustration backgrounds.
- An asset manifest: original filename, source URL or repository commit, download date, license, SHA-256 where useful, and any safe crop/compositing notes.

## Keep elsewhere / avoid

- Jade-specific security articles, feature explanations and comparisons → `../03_blockstream_jade/`.
- Finished topic-specific posters and draft images → their topic folder, not the shared originals.
- Never modify an official logo or invent hardware geometry. Composite authentic photos without stretching, cropping off device edges, or fabricating screens.

## Filing routine (keep the folder flat)

1. Save papers, images, code, links, screenshots, notes and finished posters **directly in this folder**. No required child folders.
2. Give every sourced item a readable filename; include the project/version/date when that affects accuracy. Preserve the official original filename of authentic product photos when possible.
3. For anything used in a public tweet/poster, keep the **primary source URL, checked date, relevant release/network version, and usage/redistribution rights** in a nearby `.md` note or directly below in this README.
4. Treat source documents as evidence, not permission to alter branded artwork. Before publishing, recheck time-sensitive claims and avoid exposing wallet secrets, authentication material or private user data.
