# 02_simplicity — Simplicity / SimplicityHL / tooling

Research on the **Simplicity language, formal semantics, contracts, compilers and practical applications**, primarily on Liquid.

## Put here

- Papers and specifications on combinators, typed programs, CMR/IMR commitments, Merkleized branches and resource costs.
- SimplicityHL and Smplx examples, compiler/docs, reproducible code samples, covenants, vaults and contract constraints.
- Diagrams distinguishing parameters committed at funding from witnesses supplied at spending; mainnet activation references and release notes.

- General Liquid peg-ins, assets, functionary operations → `../04_liquid_network/`.
- Post-quantum signature constructions and migration research → `../12_blockstream_quantum/`; link back to Simplicity when needed.
